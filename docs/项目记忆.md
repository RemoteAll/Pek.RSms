## 关键事实

- 配置 `Config/Sms.toml`，PascalCase 与 C# 对齐；`[[Data]]` 用 `TomlConfig::save_with_arrays` 写回（保留注释）。
- `SmsType`：0 国内通知、1 国际通知、2 国内营销、3 国际营销。
- 统一参数 `SmsRequest`：mobiles/content/template_id/template_params(保序)/call_data/send_time/extcode/session_context/sender_id/out_id；`{%key%}` 本地替换。
- 多账号兜底：`SmsSettings::enabled_for_type` 按 `(order, !is_default)` 稳定排序；`Smser::send` 失败自动切换；全失败 `SmsError::AllFailed`。
- 服务商协议：
  - 阿里云：SendSms 表单 + `HMAC-SHA1`（`POST&%2F&` + Base64）；`TemplateParam` JSON。
  - 腾讯云：`TC3-HMAC-SHA256`（content-type/host + 日期派生密钥）；API 2021-01-11；自动补 `CountryCode`（默认 +86）。
  - 烽火：JSON + `MD5(userName + ts + MD5(password))`；`BaseUrl` 自动补 `/sms`；支持代理 `X-Target-Url`/`X-Token-Code`。
  - 连陆：表单 + `MD5(userid + ts + secret)`；响应含“提交成功”即成功。
- `ExtendData` 键：`BaseUrl`、`Host`（腾讯云签名）、`InsecureTls`、`TemplateCode`、`OutId`、`SmsUpExtendCode`、`SdkAppId`、`TemplateId`、`CountryCode`、`Region`。
- 证书：默认校验；C# 统一 `.IgnoreSsl()`，Rust 用 `ExtendData: {"InsecureTls": true}` 显式关闭（更安全）。
- Cargo features：`default = [aliyun,tencent,fenghuo,lianlu]`，可裁剪；`create_client` 按 `SmsData.Name` 分发。
- 不引入异步运行时；`Smser::send_async` 用后台线程。
- 日志只记发送成功/失败/账号切换。
