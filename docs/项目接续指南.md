> **开工先读（存在则读，按序）**：`.github/copilot-instructions.md` → 本文 → `docs/用户档案.md` → `docs/项目记忆.md` → `docs/决策记录.md` 最新节。

## 1. 项目速览

- 定位：C# `Pek.Sms` 的 Rust 实现（**短信发送库**，crate `pek-rsms`）。
- 参照：`G:\Code\Pek.FrameWork\Pek.Sms`（阿里云 / 腾讯云 / 烽火 / 连陆 + 统一参数 + 事件兜底）。
- 远程仓库：`https://github.com/RemoteAll/Pek.RSms.git`（remote 名 `main`，分支 `main`）。

## 2. 常用命令（构建 / 测试 / 回归）

```powershell
cargo check
cargo test
cargo clippy --all-targets
cargo zigbuild --target x86_64-unknown-linux-musl --lib
```

- 日常写码用 `cargo check`；需要二进制时用 `cargo build --profile fast`；`--release` 只用于发布。
- 依赖下载走项目内 `.cargo/config.toml`（rsproxy 镜像）。
